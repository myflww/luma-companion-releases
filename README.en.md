## What is Luma?

Luma Companion is a desktop software project by [myflww](https://github.com/myflww), an independent developer. It brings an AI task workspace, creative spaces, and character companionship into one desktop experience.

An idea often ends up scattered between conversations, files, and tools. Luma aims to help you turn it into a clear next step, while keeping a familiar place for everyday conversation. When you want a character to take on work, a task draft lets you review the content, model, inputs, and permissions before sending it to a real work session.

## Three connected directions

| Direction | Main entry points | Usage notes |
| --- | --- | --- |
| **Work** | Workspaces, sessions, side panels, results, and task supervision | Execution depends on model connections, permissions, and service availability. |
| **Create** | Independent canvas, model management, and the theater entry | Available tools, models, and formats depend on the version and connected services. |
| **Companionship** | Character messages, the office, desktop pets, and appearance settings | Chat and work are confirmed separately. Available characters, voices, and scenes depend on the actual version. |
