## About the project

Luma Companion is a desktop software project under active development by **myflww**, an independent developer. It organizes interactions around real tasks and character companionship.

- **AI workspace:** task-centered interactions connecting AI execution with local applications.
- **Desktop pets and a virtual office:** character interactions and scene experiences on the desktop.
- **Creation and extensions:** exploration of canvas, theater, a companion website, and self-hosted services.

These areas are being refined, with implementation and delivery tracked separately for each module. This page does not represent a completed product or a public software release.
