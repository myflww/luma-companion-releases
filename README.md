## 项目介绍

Luma Companion 是由独立开发者 **myflww** 持续开发的桌面软件项目，围绕真实任务与角色陪伴组织交互体验。

- **AI 工作台**：围绕任务组织交互，连接 AI 执行能力与本机应用。
- **桌宠与虚拟办公室**：把角色互动和场景体验融入桌面。
- **创作与扩展模块**：探索画布、剧场，以及配套网站与自托管服务。

这些方向正在持续打磨，各模块的完成与交付状态分别维护。本页不代表功能已全部完成或已经公开发行。
