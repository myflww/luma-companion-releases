## Luma 是什么

Luma Companion 是独立开发者 [myflww](https://github.com/myflww) 制作的桌面软件项目。它把 AI 任务工作台、创作空间和角色陪伴放在一个桌面体验里，让一个念头可以接着聊、接着做，也有一个熟悉的角落可以回到。

Luma 希望帮你把散落在聊天、文件和工具之间的想法，整理成看得见的下一步。角色可以陪你交流；当你明确要做一项工作时，再核对任务、模型、输入和权限，把草案交给真实工作会话。

## 三个相连的方向

| 方向 | 主要入口 | 使用说明 |
| --- | --- | --- |
| **工作** | 工作区、会话、右侧面板、结果与任务监督 | 实际执行取决于模型连接、任务权限和服务状态。 |
| **创作** | 独立画布、模型管理、万象剧场入口 | 可用工具、模型与格式以所用版本及连接服务为准。 |
| **陪伴** | 角色消息、办公室、桌面宠物和角色表现设置 | 聊天与工作分开确认；可用角色、声音和场景以实际版本为准。 |
