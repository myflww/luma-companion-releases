# 支持与反馈 / Support

[项目首页](README.md) · [FAQ](docs/FAQ.md) · [快速开始](docs/QUICKSTART.zh-CN.md) · [用户手册](docs/USER_GUIDE.zh-CN.md)

这里接收 Luma 使用问题、建议与文档纠错。请先查看 [FAQ](docs/FAQ.md) 和对应版本说明，再提交尽量具体的反馈。

## 公开问题

通过 [Issue 模板](https://github.com/myflww/luma-companion-releases/issues/new/choose) 提交问题或建议。尽量提供：

- 你使用的软件版本或文档页名称。
- 操作系统和相关入口。
- 最少复现步骤、期望结果与实际结果。
- 需要时附经过隐私处理的截图或最少日志。

公开 Issue 会被他人看到。请移除 API 密钥、密码、恢复码、验证码、私人聊天、文件正文、个人路径和联系方式。普通反馈无需上传整个应用数据目录。

## 私下联系

业务合作、授权问题或包含私人资料的反馈：[1805680363@qq.com](mailto:1805680363@qq.com)。安全问题请先阅读 [安全报告方式](SECURITY.md)。

## English

Questions, suggestions, and documentation corrections are welcome. Check the [FAQ](docs/FAQ.md) and the relevant version notes, then share a specific report.

Use the [Issue templates](https://github.com/myflww/luma-companion-releases/issues/new/choose) for public reports. Include the version or document page, operating system, relevant entry point, minimal reproduction steps, and expected versus actual behavior. Share only the minimum sanitized screenshot or log needed to explain the issue.

Do not post credentials, recovery codes, verification codes, private conversations, file contents, personal paths, or contact information in public reports. For business, licensing, or private feedback, contact [1805680363@qq.com](mailto:1805680363@qq.com). For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
