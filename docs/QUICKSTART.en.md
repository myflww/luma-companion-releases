# Luma Companion Quick Start

**Updated: October 25, 2026**

[简体中文](QUICKSTART.zh-CN.md) · [Full guide](USER_GUIDE.en.md) · [Downloads](../DOWNLOADS.md)

The interface and available capabilities depend on your version and service availability. See the [download page](../DOWNLOADS.md) for version access.

1. **Enter your account.** When the account service is available, register or sign in through the startup screen. Save the recovery code shown after registration before entering Luma. Your Luma account and model-provider account are separate.
2. **Connect a model.** Open the user menu → Settings → Models (`设置 → 模型`) → Connect model API (`连接大模型 API`). Choose the provider, enter your own key and required configuration, and save. A configured key or synced catalog does not prove a successful model call. Provider charges may apply.
3. **Try a small task.** Choose Switch workbench → Workspace (`切换工作台 → 纯净工作台`). Add a dedicated example folder as a workspace and create a session. State the goal, output, and limits; select a model and appropriate permissions, then send. Start with Read only or Workspace write where appropriate.
4. **Dispatch through a character.** In character chat, set Message purpose to Work task (`消息用途 → 工作任务`) and select Draft task (`拟定任务`). Review the draft, model, and attachments. Acknowledge model input and possible costs, then Confirm task (`确认任务`). Ordinary character chat does not directly send files.
5. **Review progress and results.** Open the original task when approval or an answer is needed. Character pages offer Supervise task (`监督任务`). Check finished outputs. If status is uncertain, reread records before submitting again.

The Office employee drawer offers Send to desktop and Recall to app. Settings → Character presentation manages pets. Canvas and Wanxiang Theater can be entered through navigation or More; the specific tools depend on your version.

Chats and summaries currently use local plaintext storage; sending shares relevant input with the selected model. Screen companionship sends the whole screen to a vision-capable character model and may incur charges. Chat backups exclude work files, and GitHub source sync does not back up application data. Sign-out retains local work; use Quit Luma to exit completely.

For help, read [support instructions](../SUPPORT.md) and remove keys, recovery codes, and private content from reports.
