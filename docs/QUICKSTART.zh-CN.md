# Luma Companion 快速开始

**更新日期：2026-10-25**

[English](QUICKSTART.en.md) · [完整手册](USER_GUIDE.zh-CN.md) · [下载页面](../DOWNLOADS.md)

界面和可用能力以所用版本及服务状态为准，获取版本请见[下载页面](../DOWNLOADS.md)。

1. **进入账号。** 账号服务可用时，按登录页注册或登录。注册成功须保存只显示一次的恢复码，再进入 Luma。Luma 账号与模型服务账号不同。
2. **配置模型。** 用户菜单 →“设置 → 模型”→“连接大模型 API”。选择提供方，填写自己的 API 密钥及必要配置后保存。密钥已配置、目录已同步不等于调用成功；使用可能由提供方计费。
3. **试一项小任务。** “切换工作台 → 纯净工作台”，添加专用样例文件夹作为工作区，创建新会话。写清目标、产物与限制，选择模型和合适权限后发送。初次可从只读或工作区可写开始。
4. **从角色派发。** 打开角色聊天，将“消息用途”选为“工作任务”，点击“拟定任务”。在草案核对内容、模型与附件，勾选模型输入及费用确认，再点“确认任务”。普通聊天暂不直接发送文件。
5. **看状态与结果。** 等待审批或回答时打开原任务；角色页可“监督任务”。完成后打开成果核对，状态不明先重新读取，不重复提交。

办公室员工抽屉可“外派到桌面／召回应用”；“设置 → 角色表现”管理桌宠。画布、万象剧场可从导航或“更多”进入，具体工具以所用版本为准。

聊天与摘要当前明文存于本机；发送会交给所选模型。开启屏幕陪伴会将整屏发给支持视觉的角色模型并可能计费。聊天备份不含工作文件，GitHub 源码同步也不备份应用数据。退出登录保留本机作品；完全退出使用“退出 Luma”。

需要帮助请看[支持说明](../SUPPORT.md)，先去除密钥、恢复码和私人内容。
