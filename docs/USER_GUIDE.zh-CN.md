# Luma Companion 使用指南

**更新日期：2026-10-25**

[English](USER_GUIDE.en.md) · [快速开始](QUICKSTART.zh-CN.md) · [功能与使用条件](FEATURES.md) · [下载页面](../DOWNLOADS.md)

Luma 将文件任务、AI 角色交流与桌面陪伴放在同一个应用中。你可以在纯净工作台围绕文件和任务工作，也可以在办公室联系角色、先拟定工作草案，再确认交给模型执行。

界面和可用能力以所用版本及服务状态为准，获取版本请见[下载页面](../DOWNLOADS.md)。

## 1. 开始之前

版本获取与相关说明统一列在[下载页面](../DOWNLOADS.md)。请使用与你所用版本对应的说明。

使用模型功能通常还需要你有权使用的模型服务和 API 密钥。**Luma 账号用于进入 Luma；模型服务账号与 API 密钥用于访问模型，两者不同。** 具体支持的接口、模型和功能以应用中显示的可用状态为准。API 费用由相应提供方和你的账户方案决定，不包含“永久免费”或“无限调用”的承诺。

第一次练习可以准备一个专门的工作文件夹，放入少量不敏感的样例文件。先安排整理文本、生成清单等范围明确的任务，完成后检查成果，再逐步扩大工作范围。

## 2. 注册、登录与恢复账号

账号服务可用时，启动后按登录页提示注册或登录。界面要求连接账号服务时，按相应版本的服务说明完成连接；服务暂时不可用时，等待恢复，不要向陌生地址提交密码。

首次注册：

1. 选择“注册”，填写“登录账号”“密码”和“确认密码”。
2. 登录账号为 3–32 位，以英文字母开头，可含数字与下划线，不能与现有账号重复。密码提示为 15–128 个字符，支持中文与空格。
3. 点击“注册账号”。成功后，妥善保存页面显示的恢复码。恢复码只显示一次，请存到只有你能访问的位置。
4. 勾选“我已妥善保存恢复码”，点击“保存好了，进入 Luma”。

已有账号可填写账号密码并点击“登录 Luma”。“记住登录，下次自动进入”适用于你信任的个人电脑。使用共用设备时，应留意登录状态并在结束后退出账号。

“登录账号”和个人资料中的“用户名”用途不同：前者用于登录、不能重名；后者用于展示，可修改、可以重名。改展示名称不会改变登录账号。

旧邮箱账号可点“已有邮箱账号”，按提示验证原邮箱后设置账号密码。“忘记密码”使用已保存的恢复码重设密码；成功后会生成新恢复码，原码失效。恢复码和验证码都不要发到公开 Issue、截图或支持邮件中。

## 3. 连接模型并理解费用

打开左下角用户菜单，进入“设置 → 模型”：

1. 点击“连接大模型 API”，选择你使用的提供方。
2. 按界面填写 API 密钥；仅在需要时填写 API 地址和模型目录。已有凭据的输入框可留空以保留原值，具体以页面提示为准。
3. 使用自定义接口时，选择“自定义 API 地址”，核对提供方名称、协议、地址和模型 ID，不根据模型名字猜测接口能力。
4. 点击“保存”，再到任务或角色聊天中选择可用模型。

模型列表可能包含内置目录、提供方发现结果和手动配置。“API 密钥已配置”说明凭据已保存，“目录已同步”说明目录读取完成，**两者都不等于模型调用成功**。实际可用性还取决于接口、账户权限、余额、网络和模型能力。

聊天、工作、读屏和媒体生成功能可能使用不同模型或连接。只有提供方明确支持图片输入时，才将模型标记为支持图片；文本模型不因名称中带某个词就具备视觉能力。不要把 API 密钥粘贴进聊天任务、公共仓库、日志或问题报告。

## 4. 在纯净工作台完成第一项任务

点击左上角 Luma 的“切换工作台”，选择“纯净工作台”。在工作区列表选择已有工作区，或使用“添加工作区”选取你准备的文件夹，再在该工作区创建“新会话”。

工作区决定这项任务主要围绕哪些文件展开。第一次可以使用单独的样例目录，避免直接把整个个人文件目录交给任务。

发送前写清目标、输入、输出位置与限制。例如：

> 请阅读这个工作区中的三份样例笔记，生成一份 Markdown 待办清单，保留原文，在结果中标出需要我确认的事项。

选择可用模型，检查权限，然后发送。任务需要补充信息或审批时，先阅读提示再回答。状态含“进行中”“等待审批”“等待回答”“已完成”等；看到完成标记后，仍应打开产物核对内容与保存位置。

右上“打开右侧面板”提供变更、终端、浏览器、文件、侧边聊天和结果等内容。文件面板可浏览工作区，预览文本与常见图片；变更面板用于查看改动；结果面板汇集成果和参考链接。不同面板用途不同，参考链接不等于已经下载到本机的成果文件。

终端用于你明确需要的命令操作。切换标签不会结束终端；关闭该终端标签会结束对应终端。当前主要适用于文本交互，不能据此假定完整全屏终端程序都能正常工作。

## 5. 和角色聊天，再确认派发工作

在办公室展开员工列表，点击角色进入聊天；也可以从“消息”进入相应会话。首次使用时先阅读“确认聊天记忆说明”，再点“确认并继续聊天”。通过“更多 → 选择模型”核对该角色绑定的模型及输入费用确认。

输入框中的“消息用途”可选择“自动”“聊天”或“工作任务”。想明确安排文件工作时，选择“工作任务”，或通过“更多 → 拟定工作任务”进入草案，避免把普通聊天误当成已提交的任务。

派发步骤：

1. 输入目标，点击“拟定任务”，打开工作草案。
2. 核对任务名称与任务内容，选择“工作模型”。
3. 在“工作附件”区域拖入图片或文件，检查附件名称，移除不需要的内容。
4. 勾选“确认任务内容，并允许将工作输入交给所选模型，了解可能产生费用”。
5. 点击“确认任务”，再查看任务接收状态；状态待核实时使用“重新读取任务记录”，不要反复提交同一任务。

创建草案是准备工作，确认派发才将输入交给所选模型。角色普通聊天目前不支持直接发送图片或文件，需要附件时请打开工作草案。新派发任务可写入员工工作区，更广的权限需要另行确认。

非工作时段的新任务可能预约到下次上班，以确认界面的提示为准。办公室下班、角色外派或切换页面不会自动取消已经进行中的任务。需要检查时打开原任务，不要另建一项任务来猜测原任务的进度。

## 6. 权限、审批与任务监督

权限项包括“只读”“工作区可写”“完全访问”和“自定义”。只读适合了解文件；工作区可写允许在工作区创建和修改文件。根据任务需要选择，不确定时先从较小范围开始。

“完全访问”会减少逐步确认，并允许更多敏感操作、文件修改或外部命令。界面要求你单独了解风险后确认。它不应作为第一次使用时的默认教学步骤。

看到“等待审批”“等待回答”或角色的待确认状态时，进入原任务阅读操作目标、范围与后果，再决定是否允许或补充说明。角色页面的“监督任务”可带你查看对应任务；也可前往纯净工作台检查。批准某一步不会代替你对最终产物的核验。

任务显示“待核实”时，先重新读取记录。网络中断不一定代表请求从未提交；反复点击可能造成重复工作或额外费用。不能确认状态时，保留现有记录并通过[支持入口](../SUPPORT.md)反馈。

## 7. 办公室、角色与桌面陪伴

通过“切换工作台 → 办公室”返回场景。员工抽屉可进入角色聊天，使用“外派到桌面”让角色留在桌面，或“召回应用”让角色返回。需要调整尺寸时，打开“显示与调整 → 桌面大小”。

用户菜单中的“设置 → 角色表现”包含默认对话角色、贴边外观、屏幕陪伴、临时缓存与显示声音选项。“启用桌面宠物”“播放角色声音”“登录电脑后启动桌宠”各自控制对应行为，以当前版本显示的可用项为准。

屏幕陪伴需要单独理解和开启：**整屏画面会发送给发言角色当前绑定且支持视觉的模型，可能计费；截图不保存到磁盘。** 需要系统屏幕权限时，按应用与系统提示处理。开启前关闭不希望发给模型的内容，暂停时确认界面状态，不要把普通角色聊天与自动读屏混为一谈。

“缓存自动清理”处理临时内容，不等于清除正式聊天记录。角色外派与隐藏也不等于删除聊天或停止任务。

## 8. 画布、万象剧场与其他入口

办公室导航包含“画布”“万象剧场”等入口。常用栏没有显示时，打开“更多”寻找相应功能，并可把它加入常用栏。

画布提供创作空间入口，模型管理会连接回应用的模型设置；加载失败时可以点“重新加载画布”。万象剧场提供独立的故事体验入口。具体工具、模型和导入格式以所用版本显示的能力为准，使用前核对相应模型与资源条件。

收藏、商店、社区、娱乐等页面的可用内容取决于账号、资源和服务状态。遇到不可用提示时按页面说明处理；涉及购买或其他外部操作时，先核对具体内容与确认信息。

## 9. 数据、隐私与备份

当前角色聊天、摘要和关系成长记录明文保存在本机，尚未加密；它们用于角色交流，正式工作任务不读取角色聊天记忆。发送聊天时，会把角色设定、相关记忆和消息交给你选择的模型。不要用“本机保存”推断“不会向模型发送”。

AI 创作群聊天保存在本机，可在相应群组管理界面使用“导出聊天备份”；换设备时通过“消息”的添加菜单选择“导入创作群聊天备份”。**聊天备份不包括工作文件正文。** 工作文件需另外复制，并在新设备重新关联。导入备份不会自动启动 AI 回复或工作任务。

工作成果、聊天记录、模型设置和软件安装包是不同内容，应分别安排备份。GitHub 上的私有源码记录用于保存开发代码，不是应用运行数据或完整电脑备份；不要因此删除本机聊天、素材、模型、工作文件或唯一可用的恢复资料。归档聊天也不等于释放对应磁盘空间。

## 10. 退出、故障反馈与许可

“退出登录”用于结束当前账号状态，本机作品会保留。关闭主窗口、关闭全部桌宠与“退出 Luma”是不同操作；要完全退出，可使用应用或菜单栏中的“退出 Luma”。有任务进行时先核对状态、保存必要内容，不把窗口消失当作任务已完成。

遇到模型不可用时，依次检查所选模型、配置状态、账户权限和网络；遇到状态不明时先重新读取原记录。反馈请说明版本、操作步骤、预期与实际结果，并附去除隐私的提示截图。不要发送 API 密钥、密码、恢复码、完整聊天或敏感文件。提交方法见[支持说明](../SUPPORT.md)。

Luma 第一方源代码保持私有，使用范围和分发条件见[许可说明](../LICENSING.md)。第三方组件、模型、素材及服务分别受各自许可或条款约束。使用本指南不会授予源代码的公开、修改或再分发权利。
